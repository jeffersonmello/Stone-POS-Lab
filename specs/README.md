# Especificações do Stone POS Lab

- [001 — Base do laboratório](001-base-do-laboratorio.md)
- [Modelo para novas especificações](MODELO.md)

Use uma especificação para combinar o comportamento esperado de uma funcionalidade com a forma de verificar sua entrega. Uma correção pequena pode ser registrada na especificação existente quando alterar um critério ou quando recuperar uma informação que mereça ser preservada.

1. Leia a especificação mais próxima da mudança e revise o trecho afetado. Para um fluxo novo, crie `NNN-nome.md` a partir do modelo e adicione-o ao índice.
2. Registre o problema, o comportamento que a pessoa deve conseguir observar e as dependências de ambiente. Inclua exemplos de erro ou de recuperação quando mudarem o que será entregue.
3. Implemente e verifique os critérios com testes ou passos manuais. Registre a data, o resultado e o ambiente utilizado. Mantenha visíveis os itens que ainda dependem de terminal, SDK, credenciais de teste ou pacote autorizado.

Use os guias incluídos no aplicativo para ensinar o procedimento e o catálogo para registrar os dados de cada modelo. Ao migrar memória de conversas, protótipos ou projetos internos, traga apenas o que for verificável e publicável. Descreva a descoberta com a origem, a data e o ambiente, usando referências públicas ou evidências sanitizadas.
