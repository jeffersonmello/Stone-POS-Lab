# Política de segurança

Para relatar uma vulnerabilidade no Stone POS Lab, abra a [aba Security do repositório](https://github.com/jeffersonmello/Stone-POS-Lab/security) e use **Report a vulnerability** se o recurso estiver disponível. Caso contrário, procure um canal de contato privado indicado no [perfil do mantenedor](https://github.com/jeffersonmello).

Informe a versão ou o commit afetado, o impacto observado e os passos mínimos para reproduzir usando dados de teste. Mantenha os detalhes da vulnerabilidade fora de issues e pull requests públicos. Remova credenciais e dados pessoais ou de pagamento dos anexos.
